# Third-party files in packaging/

## runtime-x86_64

The static AppImage type-2 runtime from the AppImage project
(https://github.com/AppImage/type2-runtime, build `dd6cebe`), with its update-information
and signature sections blanked so CalLink AppImages carry no update source.
It is placed in front of the squashfs image by `build-appimage.sh`.
